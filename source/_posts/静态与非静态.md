# 静态成员与非静态成员

> 本文所有代码与输出均为 **.NET 10**测试结果

## 一、核心区别

- **`static`（静态）成员属于"类型"**：全程序只有一份，用 `类型名.成员` 访问，类型一加载就存在、进程结束才消失，不依赖任何对象。
- **非 static（实例）成员属于"对象"**：每个 `new` 出来的对象各持一份，用 `对象.成员` 访问，随对象创建而存在、随对象被回收而消失。

| 维度 | 静态成员 | 实例成员 |
|:--|---|---|
| 归属 | 类型本身 | 单个对象 |
| 份数 | **一份，所有对象共享** | 每个对象各自一份 |
| 访问 | `类名.成员`（无需对象） | `对象.成员`（必须先 new） |
| 生命周期 | 类型加载后即存在，进程内全程 | 随对象创建/回收 |
| 从"对方"里访问 | 静态方法里**不能**访问实例成员（没有 `this`） | 实例方法里**能**访问静态成员 |
| 修饰 | 字段/方法/属性/事件/构造都可 static | 其余普通成员 |

## 二、代码演示

### ① 静态字段所有对象共享一份，实例字各个对象独立

```csharp
class Counter
{
    public static int TotalCreated; // 静态字段：一份，共享
    public int Id; // 实例字段：每实例一份

    public Counter()
    {
        TotalCreated++; // 实例方法里可以访问静态成员
        Id = TotalCreated;
    }

    public static string Report() => $"Counter类型已创建 {TotalCreated} 个实例";
    public string Describe() => $"我是第 {Id} 个实例";
}

Counter a = new ();
Counter b = new ();
Console.WriteLine(Counter.Report()); // Counter类型已创建 2 个实例
Console.WriteLine(a.Describe()); // 我是第 1 个实例
Console.WriteLine(b.Describe()); // 我是第 2 个实例
```

`TotalCreated` 是类型级计数器，`a` 和 `b` 看到的都是同一个值；`Id` 是对象自己的编号。

### ② 静态类：不需要 new，直接用

```csharp
static class MathUtil
{
    public static int Double(int x) => x * 2; // 静态类里只能有静态成员
}

Console.WriteLine(MathUtil.Double(21)); // 42
```

静态类（`static class`）是"只放静态成员的工具类"：编译器强制它**不能有实例成员、不能被实例化、不能被继承**（它隐式 `abstract` + `sealed`）。

### ③ 访问规则

```csharp
class AccessDemo
{
    public static int S = 1;
    public int I = 2;

    public static void StaticCanDo()
    {
        Console.WriteLine(S);       // ✅ 静态方法访问静态字段
        // Console.WriteLine(I);    // ❌ 静态方法里没有 this，访问不了实例成员
    }
    public void InstanceCanDo()
    {
        Console.WriteLine(S);       // ✅ 实例方法访问静态字段
        Console.WriteLine(I);       // ✅ 实例方法访问自己的字段
    }
}
```

### ④ 特例：`const` 是隐式静态的编译期常量

```csharp
class Config
{
    public const int MaxRetry = 3; // 相当于 static，但值写死在编译期
}
Console.WriteLine(Config.MaxRetry); // 用类名访问，编译时被替换成 3
```

`const` 没有存储、值在编译期就替换进调用处； `static readonly` 是运行期初始化一次的静态字段。想放运行期才确定的"常量"用 `static readonly`。

## 三、静态构造方法（类型初始化器）

### 作用与特点

用来初始化**静态成员**（静态字段、静态配置）。由运行时自动触发，**每类型最多执行一次**。

| | 实例构造方法 | 静态构造方法 |
|---|---|---|
| 触发 | 每次 `new` | 首次实例化或访问静态成员**之前**自动执行一次 |
| 次数 | 每个对象一次 | 每类型一次（整个进程） |
| 能否手动调用 | 能（`new` 就是调用它） | **不能** |
| 参数/修饰符 | 可重载、可带参数、可写修饰符 | 必须无参、无访问修饰符、不能重载 |
| 与字段初始化的顺序 | 实例字段初始化先于构造体 | **静态字段初始化先于静态构造体**（合称类型初始化器） |
| 线程安全 | 无 | CLR 加锁保证：多线程同时首次访问时只有一个线程执行，其余等待 |

### 代码演示

```csharp
class Animal
{
    static Animal() => Console.WriteLine("Animal 静态构造方法");
    public Animal() => Console.WriteLine("Animal 普通构造方法");
}

class Dog : Animal
{
    static int tag = InitStatic(); // 静态字段初始化
    string nick = InitInstance(); // 实例字段初始化

    static Dog() => Console.WriteLine("Dog 静态构造方法");
    static int InitStatic()
    { Console.WriteLine("Dog 静态字段初始化"); return 1; }
    static string InitInstance()
    { Console.WriteLine("Dog 实例字段初始化"); return "x"; }

    public Dog() => Console.WriteLine("Dog() 构造方法 (没写 base，隐式调 base())");
}

_ = new Dog(); // 第一次
_ = new Dog(); // 第二次
```

实测输出：

```
第一次:
	Dog 静态字段初始化
    Dog 静态构造方法
    Dog 实例字段初始化
    Animal 静态构造方法
    Animal() 普通构造方法
    Dog() 构造方法 (没写 base，隐式调 base())
第二次:
    Dog 实例字段初始化
    Animal() 普通构造方法
    Dog() 构造方法 (没写 base，隐式调 base())
```

要点：

1. **静态部分（字段初始化 + 静态构造体）只在第一次出现**
2. 静态字段初始化先于静态构造体执行。
3. 类型初始化是"**各管各的、首次使用才触发**"：`Animal` 的静态构造**不是**随 `Dog` 类型初始化连带执行的，是在第一次调用 `Animal` 构造方法那刻才触发。
4. 实例字段初始化先于父类构造体执行。

## 四、static 用途

1. **无状态工具方法**：`Math.Max`、`Path.Combine` —— 不读对象数据，做成静态免去每次 new。
2. **全局共享状态**：计数器、进程级配置（注意多线程要加锁或用原子操作）。
3. **工厂方法**：静态方法创建并返回对象实例，如 `File.Open()`、`DateTime.Now`。
4. **程序入口**：`Main` 本身必须是静态的（没有对象存在时就需要能启动程序）。
5. **静态类承载常量与工具**：如自定义的 `AppConfig`、扩展方法所在的静态类。

**注意**：滥用静态会带来全局可变状态，让代码难以测试和并行化。
